Roland OCTA-CAPTURE Mod: Rosetta OS custom firmware

Free custom firmware for the Roland OCTA-CAPTURE (UA-1010) USB audio interface, built from Roland's own v1.51 update. Running on real units: a new boot screen, a channel strip on all 8 inputs, a guitar amp in the unit's own DSP (no PC delay) and the Rosetta Octa Control PC editor.

Build and flash

  1. Download Roland's OCTA-CAPTURE System Program Ver.1.51 (octa_sys_v151.zip) from Roland's support site.
  2. Run python tools/build_rosetta.py octa_sys_v151.zip. It writes and checks UpdOcta.dat.
  3. Hold [▶] in the PRE-AMP section and push the CURSOR/VALUE knob while powering on.
  4. Copy UpdOcta.dat onto the disk that appears, once, then unplug USB and let it write.

Before copying: the updater screen must not show [ALL]. Keep Roland's original UpdOcta.dat: flashing it the same way takes the unit back to stock. Full steps and recovery are in FLASHING.md.

Under the hood

The OCTA-CAPTURE runs on one Analog Devices Blackfin DSP (a BF52x). Its compressors, mixers, reverb and USB audio are all software on that chip.

The update file is 1 MB and maps 1:1 onto the unit's flash. The code is packed with LZSS whose history ring starts full of zeros, not spaces. Each region ends with a 16-bit byte-sum checksum that the boot code checks at every power-on.

The checksum notes and the flash safety map have the details.
